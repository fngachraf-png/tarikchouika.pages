منصة ألعاب مغربية

DTSG

منصة ألعاب رقمية للألعاب المغربية التقليدية مثل روندا ورامي، مع وضع متعدد اللاعبين وبطولات ولوحة صدارة.

زيارة الموقع المباشر

عن المشروع

منصة ألعاب الدكاء التقليدية الرقمية (DTSG) مشروعي الأكثر طموحاً: منصة تجمع الألعاب المغربية التقليدية — الروندا، الرامي، الطاولة، الضومنة، البارتشي وغيرها — وتحوّلها إلى تجربة رقمية حديثة بغرف لعب جماعية، دردشة حية، بطولات ولوحة صدارة، مع دعم الصوت والمؤثرات البصرية.

التقنيات المستخدمة

  • HTML5
  • CSS3
  • JavaScript (Vanilla)
  • اتصال حيّ عبر WebSocket
  • نظام جلسات ومصادقة
  • مؤثرات صوتية وبصرية
  • Cloudflare Pages

أبرز الميزات

  • ألعاب مغربية تقليدية متعددة
  • لعب جماعي مباشر عبر الشبكة
  • غرف لعب ودردشة حية
  • بطولات ولوحة صدارة
  • مؤثرات صوتية داخل اللعب

ماذا تعلّمت منه

أكبر درس تقني في مساري: بنية مشروع كبيرة بوحدات كود واضحة، الاتصال الحيّ بين اللاعبين، إدارة الحالات والجلسات، وأهمية التقسيم المنهجي للكود حتى يبقى المشروع قابلاً للتطوير.
