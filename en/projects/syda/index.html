About this project

SYDA is a complete Arabic e-commerce store showcasing thousands of products: home, beauty, electronics, automotive and more. It provides a full Arabic shopping experience: category browsing, an interactive cart, order tracking, and a live customer-service chat — with the spirit of a modern, fast Moroccan shop.

Technologies used

  • HTML5
  • CSS3
  • JavaScript
  • Interactive shopping cart
  • Live customer-service chat
  • Category browsing
  • Cloudflare Pages

Key features

  • Thousands of products in clear categories
  • Shopping cart and order tracking
  • Live chat with customers
  • Fully Arabic interface
  • Fast mobile experience

What I learned from it

It sharpened my commercial thinking: how large product catalogs are organized, how a complete customer journey is designed from browsing to ordering, and how customer service is approached digitally with the café mindset — the customer first.
