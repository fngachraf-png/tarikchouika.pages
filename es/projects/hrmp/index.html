HRMP

Plataforma marroquí de gestión de recursos humanos que cubre reclutamiento, planificación, asistencia y nóminas conforme al código laboral marroquí.

Visitar el sitio en vivo

Sobre el proyecto

HRMP es una plataforma marroquí de gestión de recursos humanos diseñada para organizar todo el ciclo de trabajo: contratación, planificación de turnos, seguimiento de asistencia y ausencias, y cálculo de nóminas conforme al código de trabajo marroquí. El proyecto combina una interfaz de usuario práctica con servicios backend que funcionan a través de un túnel seguro, ofreciendo una solución administrativa realista.

Tecnologías utilizadas

  • HTML5
  • CSS3
  • JavaScript
  • Servicios backend mediante túnel seguro
  • Gestión de datos de empleados
  • Cálculo de nóminas y turnos
  • Cloudflare Pages

Características clave

  • Gestión de contratación y expedientes de empleados
  • Planificación de turnos y asistencia
  • Nóminas alineadas con el código de trabajo
  • Informes administrativos organizados
  • Interfaz práctica en árabe

Lo que aprendí

Me acercó al mundo real de los negocios: entender necesidades administrativas complejas — turnos, asistencia, nóminas — y traducirlas en un sistema utilizable, y por qué toda solución digital debe cumplir la ley local (el código de trabajo marroquí).
